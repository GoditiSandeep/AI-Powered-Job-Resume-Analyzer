# AI-Powered Job & Resume Analyzer

An AI-powered career assistant that analyzes resumes, evaluates ATS compatibility, identifies skill gaps, and helps users improve their resumes for targeted job opportunities.

## 🚀 Features

- 📄 Resume upload and text analysis
- 🤖 AI-powered resume analysis
- 📊 ATS compatibility scoring
- 🔍 Keyword and skill matching
- 💡 AI-based resume improvement suggestions
- 💼 Job browsing and matching
- 🎯 Target job title optimization
- 📈 Skill gap analysis
- 📝 Resume sections analysis
- 👤 User authentication
- 🛠️ Admin portal
- 📱 Responsive web interface
